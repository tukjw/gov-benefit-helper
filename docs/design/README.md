# 화면 디자인 채택 범위

웹 화면(F1~F4, [개발 순서](../product/development.md))을 만들 때 디자인 시안에서 무엇을 따르고 무엇을 대체하는지 정한다. 시안과 이 문서가 다르면 이 문서를, 이 문서와 제품 문서(`REQ-*`, `DEC-*`)가 다르면 제품 문서를 따른다.

> **예시 데이터 주의**: 프로토타입에 나오는 혜택 17건은 정책 이름만 실제이고 금액·신청 기간·판정 조건은 시안용 예시다. 사실이 아니므로 구현·테스트 데이터로 쓰지 않는다. 시안의 예시 데이터 파일(`data/benefits.sample.json`)은 보관하지 않았다.

## 시안

- 출처: Claude Design 핸드오프 "정부 혜택 도우미". 2026-10-23에 받았다(#66).
- 보관: [`handoff/`](handoff/)에 원본을 고치지 않고 둔다. 시안이 바뀌면 사본을 통째로 교체하고 이 문서를 고친다.
  - [`handoff/README.md`](handoff/README.md): 화면별 수치, 공통 컴포넌트, 디자인 토큰, 접근성 체크.
  - `handoff/prototype/gov-benefit-helper.dc.html`: 전체 화면 프로토타입. `support.js`는 실행용 런타임이다.
- 프로토타입 여는 법: `handoff/prototype/gov-benefit-helper.dc.html`을 브라우저로 연다. React와 글꼴을 CDN에서 받으므로 인터넷이 필요하다. 첫 화면은 간편인증 로그인이고, 상단 메뉴와 로고로 다른 화면에 간다.
- 화면 수치는 시안 README를 그대로 참고한다. 이 문서에는 수치를 옮겨 적지 않는다.

## 채택

- **디자인 토큰**: 색, 타이포그래피, 간격, 모서리, 컨트롤 높이, 그림자(시안 README '디자인 토큰'). 본문 최소 15px, 입력·버튼 16~18px 기준도 따른다.
- **공통 레이아웃**: 페이지 컨테이너(최대 1280px), 데스크톱·모바일 헤더 구조(900px 기준), 푸터 구조, 브레드크럼, 토스트.
- **공통 컴포넌트**: 혜택 카드(카드 전체를 상세 링크로, 저장 버튼은 형제 요소로), 칩 버튼(`aria-pressed`), 라디오 카드(`role="radiogroup"`), 단계 표시, 입력과 에러 표시(`aria-invalid`, `aria-describedby`, `role="alert"`), 빈 상태, 사이드 박스, 안내 박스(성공·경고·위험 색).
- **접근성**: 시안 README '접근성 체크'(KWCAG 2.2)를 따르고, 시안에 없는 본문 바로가기를 더한다. 전환 애니메이션 없이 hover 색 변화만 둔다.
- KRDS 공식 컴포넌트는 쓰지 않고 위 토큰과 수치를 따른다([결정 0026](../decisions/0026-frontend-styling-and-preferences.md), #72).

## 공식 정부 사이트 요소

이 서비스는 정부 공식 누리집이 아니다. 공식 사이트로 오인될 수 있는 요소는 쓰지 않는다.

- 쓰지 않음:
  - 공식 배너(Masthead)와 태극기, "이 누리집은 대한민국 공식 전자정부 누리집입니다." 문구.
  - 정부 상징 로고. 시안의 상징 자리는 서비스 이름 글자 로고로 바꾼다.
  - 푸터의 '웹 접근성 품질인증' 링크. 받지 않은 인증이다.
- 대신 넣을 민간 서비스 안내는 푸터에 둔다. 배너 자리에 안내 띠는 두지 않는다(#72).
  - 서비스 이름 아래: "정부 공식 누리집이 아닌 민간 서비스입니다. 신청 자격과 절차는 각 기관의 공식 안내에서 확인하세요."
  - 주소·콜센터 자리: 데이터 출처([공공데이터포털 행정안전부 대한민국 공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do))와 문의 메일.

## 화면별

### 공통

- 따름: 컨테이너, 헤더 구조, 모바일 메뉴, 브레드크럼, 토스트.
- 대체: 배너·상징은 글자 로고로 바꾸고 민간 서비스 안내는 푸터에 둔다. 메뉴는 양 끝 정렬 대신 로고 바로 오른쪽에 붙인다(#72, 1차 공개 메뉴가 '전체 혜택' 하나뿐이다). 유틸리티 줄에는 로그인·회원가입(#73)을 둔다. 메뉴는 조건 비교 / 전체 혜택 / 관심 혜택이다. '맞춤 혜택 찾기'는 '조건 비교'로 바꾸고 '신청 마감 알림'은 뺀다. 로그인 버튼은 '로그인'이다(간편인증 아님).
- 더함: 본문 바로가기.

### F1 검색·상세 공개 화면

시안 1. 홈, 3. 전체 혜택, 4. 혜택 상세.

- 홈
  - 따름: 히어로와 검색창, 검색어 칩(검색어만 넘긴다).
  - 대체: "많이 찾는 검색어"는 "추천 검색어"(고정 목록). 검색 기록을 모으지 않으므로 "많이 찾는"은 사실이 아니다(#72). 대상별 바로가기는 분야 바로가기(건수 없음). 맞춤 찾기 카드는 조건 비교 카드("로그인 없이 내 조건과 비교해 보기").
  - 뺌: 신청 마감 임박 목록, 마감 알림 받기 카드.
- 전체 혜택
  - 따름: 검색창, 필터 사이드바와 결과 영역의 2단 구성, 모바일 필터 토글, 카드형·목록형 전환, 빈 상태와 필터 초기화.
  - 대체: 필터는 분야·운영 기관 유형·운영 기관 지역. 운영 기관 지역은 거주 요건이 아님을 필터 이름이나 설명에 드러낸다(`REQ-SEARCH-01`). 카드의 D-day와 금액 자리는 신청기한 원문·표시 상태와 기관 유형.
  - 뺌: 생애주기·온라인 신청 필터, 필터별 건수, 정렬 선택, '내 조건에 맞는 혜택만'.
  - 더함: 항목의 마지막 확인 시각.
- 혜택 상세
  - 따름: 헤더 영역(분야 배지, 제목, 기관·부서, 요약), 본문과 신청 사이드 박스의 2단 구성, 섹션 제목 구성, 문의처 표, 관심 저장 토글.
  - 대체: 지원 내용·대상·선정기준·신청 방법·구비서류는 API 원문 섹션. D-day는 신청기한. 사이드 박스는 신청기한·신청 방법·접수기관과 신청 버튼(온라인 신청 주소가 있을 때만). 자격 판정 박스는 F3의 조건 비교 결과로 바꾼다.
  - 뺌: 금액 강조 박스, 신청 절차 단계 카드, 함께 보면 좋은 혜택.
  - 더함: 출처 수정 시각과 수집 시각, 공식 안내 페이지 링크.

### F2 가입·로그인

시안 7. 간편인증 로그인.

- 따름: 가운데 단일 열 폼(최대 560px), 라벨·입력 높이·에러 표시, 로그인 후 원래 화면으로 돌아가기(`returnTo`), 로그인 토스트.
- 대체: 간편인증 제공자 선택과 인증 대기 화면은 이메일·비밀번호 입력으로 바꾼다.
- 더함: 가입(이메일 인증번호 확인 후 가입), 로그아웃.

### F3 프로필·관심 혜택·조건 비교

시안 2. 맞춤 혜택 찾기, 4. 상세의 자격 판정 박스, 5. 관심 혜택.

- 프로필
  - 따름: 단계 표시, 폼 카드, 칩 버튼, 하단 이전·다음 버튼. 단계로 나눌지 한 화면에 둘지는 F3에서 정한다.
  - 대체: 만 나이는 생년월일, 시도는 시도·시군구, 가구 상황·현재 상황은 API의 가구·생애 속성 선택지. "입력한 정보는 저장되지 않습니다"는 비회원에게만 보인다. 로그인 사용자는 저장·수정한다.
  - 뺌: 소득 수준 단계.
  - 더함: 성별.
- 조건 비교 결과
  - 따름: 입력 조건 요약 박스(조건 수정·처음부터 다시), 카드 그리드, 항목별 이유 목록, 결과별 색(해당은 성공 색, 확인 필요는 경고 색).
  - 대체:
    - 결과 이름은 해당·확인 필요·미해당이다(`REQ-MATCH-01`). 미해당은 개인 대상이 아닌 혜택에만 쓰며 조건 비교 목록에는 나오지 않는다.
    - "신청할 수 있는 혜택 N건"은 "조건 비교 결과 N건"으로, 정렬은 해당 → 확인 필요, 이름순이다.
    - 해당 박스 제목 "입력한 조건으로 신청할 수 있는 혜택입니다"는 확정이 아님을 담은 문구로 바꾼다.
  - 더함: 지역 범위 선택, 비교하지 않은 조건, 해석 규칙 안내, 원문과 공식 안내 링크.
  - 문구 예시. 안내는 응답의 `notices`로 고르고, '지원조건 코드' 같은 내부 용어를 쓰지 않는다.

    | 상황 | 예시 |
    | --- | --- |
    | 해당 | 배지 "해당" + "공개된 대상 조건과 입력한 정보를 비교한 결과예요. 실제 지원 여부는 담당 기관 심사로 정해져요." |
    | 확인 필요 | 배지 "확인 필요" + "일부 조건은 직접 확인해야 해요." + 항목별 이유와 공식 안내 링크 |
    | 미해당(상세) | 배지 "미해당" + "개인이 아닌 기관·사업자 대상 혜택이에요." |
    | 지역 항목 | "거주 요건이 아니라 운영 기관이 있는 지역으로 비교했어요." |

- 관심 혜택
  - 따름: 카드 그리드, 별 버튼으로 바로 해제, 빈 상태와 바로가기 버튼.
  - 대체: 비로그인은 목록 대신 로그인 안내.
  - 뺌: 마감 알림 안내 박스, 마감순 문구.

### F4 비밀번호 재설정·탈퇴

시안에 없다. F2의 단일 열 폼과 입력·에러 표시, 안내 박스로 구성한다(위 '시안에 없는 P0 화면과 표시').

### 범위 밖

시안 6. 신청 마감 알림은 3차 알림(`DEC-NOTIFY`) 전까지 만들지 않는다.
