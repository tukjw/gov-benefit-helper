# Handoff: 정부 혜택 도우미 (Gov Benefit Helper)

## 개요
나이·지역·가구·소득·현재 상황을 입력하면 신청할 수 있는 정부 혜택을 추천하고, 관심 혜택을 저장해 신청 마감 알림을 받는 반응형 웹 서비스입니다. 스타일은 KRDS(범정부 UI/UX 디자인 시스템)를 그대로 따릅니다.

주요 사용자: 청년, 신혼·출산·육아 가구, 중장년·어르신, 전 국민.

## 디자인 파일에 대해
`prototype/` 안의 파일은 **HTML로 만든 디자인 참고 자료**입니다. 화면 모양과 동작을 보여주는 프로토타입이며, 그대로 복사해서 쓰는 운영 코드가 아닙니다. 대상 코드베이스의 기존 환경(React, Next.js, Vue 등)과 그 패턴·라이브러리로 **다시 구현**해야 합니다. 아직 환경이 없다면 Next.js(App Router) + TypeScript + KRDS 공식 React 컴포넌트(`krds-react` 또는 KRDS 공식 HTML/CSS 패키지)를 권장합니다.

- 프로토타입 실행: `prototype/gov-benefit-helper.dc.html`을 `support.js`와 같은 폴더에 두고 브라우저로 엽니다(인터넷 연결 필요: Pretendard 웹폰트 CDN).
- 화면 상태 로직은 파일 하단 `<script data-dc-script>` 안의 `class Component`에 있습니다. `renderVals()`가 템플릿에 값을 넘기는 부분이고, 판정 로직은 `match()` 함수입니다.
- `data-props` 속성: `startPage`(첫 화면), `demoLoggedIn`, `listLayout`은 시안 확인용이므로 구현하지 않아도 됩니다.

## 완성도
**하이파이(Hi-fi).** 색상, 타이포그래피, 간격, 상호작용이 최종안입니다. 다만 KRDS 공식 컴포넌트가 있다면 그 컴포넌트를 우선 쓰고, 이 문서의 수치는 레이아웃·간격 기준으로 맞춰 주세요.

**플레이스홀더(실제 자산으로 교체 필요):** 정부 상징(로고), 대상별 바로가기 아이콘, 간편인증 제공자 로고, 인증 대기 화면 앱 아이콘 → 빗금 패턴 박스로 표시되어 있습니다.

**데이터:** 정책 이름은 실제 정책이지만 금액·신청 기간은 **시안용 예시**입니다. 운영 시 공식 데이터로 교체해야 합니다(아래 "데이터" 참고).

### 자격 판정 로직 (`match(benefit, profile)`)
순서대로 확인하고, 처음 걸리는 조건에서 탈락 사유를 반환합니다.
1. `eligibleAge [min,max]` — 나이 범위 밖이면 탈락("만 19~34세 대상입니다. (입력: 만 40세)"; max ≥ 100이면 "만 N세 이상")
2. `requiredHouseholdAny` — 가구 상황 중 하나도 없으면 탈락
3. `requiredStatusAll` — 현재 상황에 모두 있어야 함(예: 무주택)
4. `requiredStatusAny` — 현재 상황 중 하나 이상
5. `maxMedianIncomePct` — 사용자가 '잘 모름'이면 통과 + `check=true`("소득 확인 필요"), 기준 초과면 탈락
- 통과 시 이유 최대 3개, 조건이 하나도 없으면 "조건 없이 누구나 신청 가능"
- 지역은 현재 판정에 쓰지 않음(지자체 혜택 연동 시 추가)
- 화면에는 반드시 "실제 자격은 소관 기관 심사로 확정됩니다."를 함께 노출

- 선택 상태는 색 + 체크 표시/글자 굵기로 함께 표현(색만으로 구분하지 않음)
- 토글 버튼 `aria-pressed`, 라디오 그룹 `role="radiogroup"`/`aria-checked`, 현재 메뉴 `aria-current="page"`
- 에러 `role="alert"`, 토스트 `role="status"`
- 본문 바로가기(skip link) 추가 필요(프로토타입에는 없음)

## 파일
- `prototype/gov-benefit-helper.dc.html` — 전체 화면 인터랙티브 프로토타입(템플릿 + 로직)
- `prototype/support.js` — 프로토타입 실행용 런타임(구현에는 불필요)
- `data/benefits.sample.json` — 예시 혜택 데이터 17건
