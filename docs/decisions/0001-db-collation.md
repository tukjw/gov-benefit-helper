# 0001. DB 문자 집합과 정렬 규칙

- 상태: 채택
- 날짜: 2026-09-27
- 출처: #1, [플랜](../plans/1-backend-init.md)

## 배경

혜택 이름 검색과 정렬은 DB의 문자열 비교 규칙을 따른다. 로컬 DB와 테스트 DB의 정렬 규칙이 다르면 테스트에서 확인한 비교·정렬 결과가 로컬과 운영에서 달라진다.

## 결정

문자 집합은 `utf8mb4`, 정렬 규칙은 `utf8mb4_0900_ai_ci`로 한다. 로컬 DB와 테스트 DB의 서버 옵션에 명시한다.

## 근거

- `utf8mb4_unicode_ci`는 이모지를 모두 같은 값으로 비교하고 끝 공백을 무시한다(로컬 MySQL 8.4에서 확인). 그래서 제외했다.
- `utf8mb4_0900_ai_ci`는 MySQL 8.4의 기본값이다. 그래도 명시하는 이유는 환경 간 일치를 설정에서 바로 확인할 수 있게 하기 위해서다.
- 이미 만들어진 DB의 기본 정렬 규칙은 서버 옵션을 바꿔도 바뀌지 않는다. 로컬 볼륨을 새로 만들어야 적용된다.

## 적용 위치

- `docker-compose.local.yml`: `--character-set-server`, `--collation-server`
- `backend/src/test/java/kr/govbenefit/TestcontainersConfiguration.java`: 같은 서버 옵션

## 영향

- 새 테이블과 문자열 컬럼은 DB 기본값을 따르고, 다른 정렬 규칙이 필요하면 이 결정을 대체하는 문서를 먼저 둔다.
- 이름 검색·정렬의 동작과 테스트는 이 정렬 규칙을 기준으로 한다.
- 운영 DB를 구성할 때 같은 문자 집합과 정렬 규칙을 쓴다.
